
# 📊 Retail Sales Analysis Dashboard | Power BI

An interactive Retail Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, profitability, customer segments, product categories, and regional business trends.

## 📌 Project Overview

This project focuses on analyzing retail sales data and converting raw data into meaningful business insights.

The dashboard provides an overview of sales, profit, orders, average order value, profit margin, monthly trends, regional performance, and product category analysis.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track monthly sales and profit trends.
- Identify top-performing product categories.
- Compare sales across different regions.
- Analyze top 5 products by sales.
- Understand customer segment performance.
- Create interactive business reports.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

## 📂 Dataset Information

The project uses a fictional retail sales dataset containing **1,000 records and 15 columns**.

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Order Date | Date of order |
| Customer | Customer name |
| Segment | Customer segment |
| Region | Sales region |
| Category | Product category |
| Subcategory | Product subcategory |
| Product | Product name |
| Quantity | Units sold |
| Unit Price | Price per unit |
| Discount | Discount applied |
| Sales | Total sales |
| Cost | Product cost |
| Profit | Profit earned |
| Payment Mode | Payment method |

## 🔍 Key Business Insights

1. **Technology Leads Sales:** Technology contributes approximately 69.63% of total sales, making it the leading product category.

2. **July Records Highest Sales:** July recorded approximately ₹33.33 lakh in sales and ₹7.41 lakh in profit.

3. **West Region Leads Performance:** The West region generated approximately ₹63.70 lakh in sales, making it the highest-performing region.

*Note: All insights are based on the fictional dataset used in this project.*
